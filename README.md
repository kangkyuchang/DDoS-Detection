# DDoS Detection
본 프로젝트는 1D CNN, LSTM, AutoEncoder 등의 딥러닝 아키텍처를 활용하여, 네트워크 트래픽 내의 이상 징후를 실시간으로 포착하고 미지의 DDoS 공격 유형까지 탐지할 수 있는 고성능 보안 엔진을 구축하는 것을 목표로 합니다.
### 1. 배경
최근 발생한 대규모 온라인 대회(예: 2024년 LCK DDoS 공격 사건)에서도 알 수 있듯이, **DDoS(분산 서비스 거부)공격**은 저렴하고 쉬운 도구로 실행 가능하며, 서버 운영 시 가장 빈번하고 치명적인 위협입니다.
다양한 공격 유형으로 인해 방어가 어렵고 **24시간 실시간 모니터링**이 필수적으로 요구되어집니다.  
특히, **Syn Flooding**과 **UDP Flooding**은 가장 흔하게 발생하는 L3/L4 계층 공격 유형으로, 서비스 마비를 초래하여 기업 및 서비스 제공자에게 막대한 금전적, 신뢰적 손실을 입힙니다.
### 2. 연구 범위 및 목표
| 목표 항목 | 핵심 내용 |
|:---|:---|
| **핵심 공격 유형 탐지** | SYN 및 UDP Flooding 공격을 식별하는 이진 분류(Binary Classification) 모델 개발 |
| **정량적 성능 목표** | **90% 이상**의 높은 **탐지 정확도** 달성 |
| **일반화 성능 검증** | 가장 기초적인 공격 유형인 SYN/UDP Flooding 학습만으로 반사 기반 공격 및 기타 미지의 DDoS 공격까지 유효하게 탐지할 수 있는지 범용성 검증 |

# 데이터 전처리
### 1. 데이터 전처리 및 변환
`inf` 값을 결측치로 변환 후, 이상치 영향을 최소화하기 위해 각 피처의 **최댓값**으로 대체하였습니다.
### 2. 정규화
- **RobustScaler 도입**: 초기 `MinMaxScaler` 사용 시 SYN Flooding 탐지 성능이 저하되는 문제가 발생했습니다. 이는 이상치에 민감한 스케일러 특성이 SYN 공격의 비정상적 분포를 왜곡했기 때문으로 분석되었으며, 이를 해결하기 위해 이상치에 강건한 `RobustScaler`로 전환하였습니다.
### 3. 특징 공학
- **피처 제거**: 특정 환경에 과적합되는 것을 방지하기 Flow ID, 출발지/목적지 IP/Port, 타임스탬프, 프로토콜, Inbound, 유사 HTTP 등 **식별자**나 **특정 공격에 의존 가능한 총 9개의 열을 제외**했습니다.
- **시계열 특성 반영**: 시간 흐름에 따른 트래픽 패턴 학습을 위해 **슬라이딩 윈도우(Sliding Window)** 기법을 적용했습니다.

<br>

# 모델링 및 실험
핵심 목표인 **SYN/UDP Flooding 탐지**를 넘어 **다양한 미지의 공격 유형에 대한 일반화된 탐지 능력**을 확보하기 위해, 다양한 딥러닝 모델 아키텍처와 비정상 탐지 기법을 결합하는 실험을 진행했습니다.
### 1. 모델 선택 근거
| 모델 아키텍처 | 특징 |
|:---|:---|
| **1D CNN** | 빠른 연산 속도로 실시간 탐지에 최적화 |
| **1D CNN + LSTM** | CNN의 특성 추출과 LSTM의 시계열 의존성 학습 능력을 결합 |
| **1D CNN + AutoEncoder** | 정상 데이터(BENIGN)만으로 학습하여 미지의 공격을 탐지하는 비정상 탐지(Anomaly Detection) 방식 도입 |
<br>

### 2. 모델 아키텍처
| 모델 아키텍처 | 구성 |
|:---|:---|
|**1D CNN** | `Conv1D(64/128) -> BatchNormalization -> MaxPooling -> Dropout -> Dense(256)` |
|**1D CNN + LSTM**| `Conv1D(64) -> LSTM(128/64) -> Dense(128)` |
|**1D CNN + AutoEncoder**| `Encoder(Conv1D-64/128) -> Decoder(Conv1D-128/64) -> UpSampling` |

<br>

# 결과 해석
- **1D CNN + AutoEncoder(미지의 공격 특화)**: 학습하지 않은 공격 유형을 100% 탐지해냈습니다. 오차의 97%를 임계치로 설정함에 따라 타 모델 대비 정밀도는 다소 낮았으나, 결과적으로 모든 공격 유형에서 가장 높은 F1-Score를 기록하며 일반화 능력을 입증했습니다.
- **1D CNN(익스플로잇 기반 공격)**: 익스폴로잇 기반 공격에서는 높은 탐지율과 F1-Score를 보였으나, 반사 기반 공격에서는 특정 유형을 제외하고 대부분 90% 미만의 성능을 기록하며 한계를 보였습니다.
- **1D CNN + LSTM(반사 기반 보완 및 특정 취약점)**: 1D CNN에서 낮았던 반사 기반 공격 성능을 대폭 향상시켰습니다. 다만, **DrDoS_NTP** 유형은 거의 탐지하지 못하는 경향이 발생했습니다. 이는 **NTP 반사 공격 특유의 정적인 시퀀스 패턴**이 LSTM 레이어에서 정상 트래픽의 지속적인 흐름과 오인되었거나, 급격히 증폭된 수치가 모델의 수치적 안정성을 저해한 결과로 분석됩니다.

<br>

# 결론 및 향후 연구
- **탐지 실효성**: 본 연구를 통해 **Syn/UDP Flooding 공격 유형만으로도 전반적인 DDoS 공격을 탐지하는 것이 충분히 가능하다**는 것을 확인했습니다. 다만, 예측 정확도를 극대화하기 위해서는 향후 **반사 기반 공격 유형을 포함한 보완 학습**이 병행되어야 합니다.
- **오탐 방지 및 가용성**: `1D CNN + AutoEncoder`가 일반화 측면에서 가장 강력했으나, 실제 서비스 환경에서 정상 사용자를 차단하는 오탐(False Positive) 문제는 서비스 가용성에 치명적일 수 있습니다. 따라서 정밀도 향상을 위한 정교한 임계치 조정이 핵심 과제가 될 것입니다.
- **실시간성 및 경량화**: 실시간 보안 운영을 위해 **모델 복잡도와 탐지 성능 간의 트레이드오프**를 고려해야 합니다. 충분한 탐지가 가능하다면, 덜 복잡하고 가벼운 모델로의 최적화를 설계 단계에서 검토할 예정입니다.
