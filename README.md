# DDoS Detection
본 프로젝트는 1D CNN, LSTM, AutoEncoder 등의 딥러닝 아키텍처를 활용하여, 네트워크 트래픽 내의 이상 징후를 실시간으로 포착하고 미지의 DDoS 공격 유형까지 탐지할 수 있는 고성능 보안 엔진을 구축하는 것을 목표로 합니다.
### 1. 배경
최근 발생한 대규모 온라인 대회(예: 2024년 LCK DDoS 공격 사건)에서도 알 수 있듯이, **DDoS(분산 서비스 거부)공격**은 저렴하고 쉬운 도구로 실행 가능하며, 서버 운영 시 가장 빈번하고 치명적인 위협입니다.
다양한 공격 유형으로 인해 방어가 어렵고 **24시간 실시간 모니터링**이 필수적으로 요구되어집니다.  
특히, **Syn Flooding**과 **UDP Flooding**은 가장 흔하게 발생하는 L3/L4 계층 공격 유형으로, 서비스 마비를 초래하여 기업 및 서비스 제공자에게 막대한 금전적, 신뢰적 손실을 입힙니다.
### 2. 연구 범위 및 목표
| 목표 항목 | 핵심 내용 |
|:---|:---|
| **핵심 공격 유형 탐지** | SYN 및 UDP Flooding 공격을 식별하는 이진 분류(Binary Classification) 모델 개발 |
| **정량적 성능 목표** | **90% 이상**의 높은 **탐지 정확도** 달성 |
| **실시간성 확보** | 실제 서비스 환경 적용을 위해 5ms 이하의 탐지 시간 달성 |
| **일반화 능력 검증** | 학습에 사용되지 않은 미지의 DDoS 공격 유형에 대한 탐지 능력 평가 |

# 데이터 분석
### 1. 데이터 출처 및 구성
| 구분 | 데이터셋 명 | 특징 |
|:---|:---|:---|
| **주 데이터(학습/검증)** | `CIC-DDoS2019` | 총 **12만 개**의 데이터(BENIGN, Syn Flooding, UDP Flooding 각 4만 개)를 **균형 있게 구성** |
| **평가 데이터** | `CIC-DDoS2019 Evaluation(Kanggle)` | **22만 개**의 행으로, 모든 DDoS 공격 유형을 **'DDoS'** 레이블로 통합 |
### 2. 데이터 분석 결과
결측치는 존재하지 않았으나, 2개의 피처 열에서 `inf` 값이 발견되어 전처리 단계에서 정제하였습니다.  

<br>

# 데이터 전처리
### 1. 데이터 전처리 및 변환
`inf` 값을 결측치로 변환 후, 이상치 영향을 최소화하기 위해 각 피처의 **중앙값**으로 대체하였습니다.
### 2. 정규화
- **RobustScaler 도입**: 초기 `MinMaxScaler` 사용 시 SYN Flooding 탐지 성능이 저하되는 문제가 발생했습니다. 이는 이상치에 민감한 스케일러 특성이 SYN 공격의 비정상적 분포를 왜곡했기 때문으로 분석되었으며, 이를 해결하기 위해 이상치에 강건한 `RobustScaler`로 전환하였습니다.
### 3. 특징 공학 및 선택
- **피처 제거**: 출발지/목적지 IP/Port, 타임스탬프, 레이블, Inbound, 유사 HTTP 등 **식별자**나 **단일 트래픽 특성**를 포함 8개 열 제외했습니다.
- **피처 선택**: Random Forest 중요도와 **RFECV(재귀적 특징 제거)** 기법을 결합하여 최적의 **21개 핵심 특징**을 추출했습니다.
- **시계열 반영**: 시간 흐름에 따른 트래픽 패턴 학습을 위해 **슬라이딩 윈도우(Sliding Window)** 기법을 적용했습니다.

<br>

# 모델링 및 실험
핵심 목표인 **SYN/UDP Flooding 탐지**를 넘어 **다양한 미지의 공격 유형에 대한 일반화된 탐지 능력**을 확보하기 위해, 다양한 딥러닝 모델 아키텍처와 비정상 탐지 기법을 결합하는 실험을 진행했습니다.
### 1. 모델 선택 근거
| 모델 아키텍처 | 특징 |
|:---|:---|
| **1D CNN** | 빠른 연산 속도로 실시간 탐지에 최적화 |
| **1D CNN + LSTM** | CNN의 특성 추출과 LSTM의 시계열 의존성 학습 능력을 결합 |
| **1D CNN + AutoEncoder** | 정상 데이터(BENIGN)만으로 학습하여 미지의 공격을 탐지하는 비정상 탐지(Anomaly Detection) 방식 도입 |
<br>

### 2. 모델 아키텍처
| 모델 아키텍처 | 구성 |
|:---|:---|
|**1D CNN** | `Conv1D(64/128) -> BatchNormalization -> MaxPooling -> Dropout -> Dense(256)` |
|**1D CNN + LSTM**| `Conv1D(64) -> LSTM(128/64) -> Dense(128)` |
|**1D CNN + AutoEncoder**| `Encoder(Conv1D-64/128) -> Decoder(Conv1D-128/64) -> UpSampling` |

<br>

# 평가
### 1. 평가지표 선택 이유
- **Accuracy**: 보안 AI 프로젝트의 초기 지표로 채택 (※ 추후 F1-score가 보안 탐지에서 더 적절함을 인지함)
- **Detection Time**: 실시간 운영 가능 여부를 판단하기 위한 필수 지표
### 2. 모델별 성능 비교 분석
| 모델 아키텍처 | 모든 공격 정확도 | SYN 공격 정확도 | UDP 공격 정확도 | 평균 탐지 시간 | 핵심 해석 |
|:---|:---|:---|:---|:---|:---|
| **1D CNN** | **43.63%** | **100.00%** | **99.99%** | **3ms** | 훈련된 패턴에 극도로 강하지만, 미지의 공격에 대한 일반화 능력 부족 |
| **1D CNN + LSTM** | **46.86%** | **100.00%** | **100.00%** | **5ms** | 시계열 특징을 추가하여 **일반화 성능이 소폭 개선**되었으나, **탐지 시간 증가**(실시간 처리 효율성 저하) |
| **1D CNN + AutoEncoder** | **77.88%** | **0.00%** | **100.00%** | **1ms** | 미지 공격에 대한 **일반화 능력 대폭 향상, 실시간 처리 속도 최적화** 다만, 학습 방식의 근본적 문제로 특정 공격 유형 탐지 실패 |

<br>

# 결과 해석
- **미지의 공격 탐지**: 1D CNN + AutoEncoder 모델은 학습하지 않은 공격 유형이 포함된 데이터셋에서 타 모델 대비 31% 이상의 정확도 향상을 보이며 탁월한 일반화 능력을 입증했습니다.
- **탐지 효율성**: AutoEncoder는 평균 1ms의 탐지 시간을 기록하며 가장 빠른 속도를 보였습니다.
- **한계점 발견**: AutoEncoder가 SYN Flooding을 탐지하지 못하는 현상이 발생했습니다. 이는 'ACK Flag Count' 등 SYN 공격의 핵심 특징이 피처 선택 과정(21개)에서 제외되어, 모델이 공격 트래픽을 정상의 범주로 오인한 것으로 분석됩니다.

<br>

# 결론 및 향후 연구
- **결론**: `1D CNN + LSTM`은 알려진 핵심 공격(SYN/UDP)에 대해 완벽한 탐지율을 보였으며, `1D CNN + AutoEncoder`는 미지의 위협에 대한 대응 가능성을 보여주었습니다.
- **향후 과제**: 도메인 지식을 바탕으로 한 특징 추출(Feature Extraction) 프로세스를 고도화하여, 'ACK Count'와 같은 핵심 지표를 반영할 예정입니다. 이를 통해 미지의 공격과 SYN Flooding 모두를 90% 이상의 성능으로 탐지하는 통합 모델을 구축하고자 합니다.
